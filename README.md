# SimpleCalculator
This is a basic calculator application built using Java Swing, the standard GUI toolkit for Java. It performs simple arithmetic operations such as addition, subtraction, multiplication, and division.

Java Swing Calculator
A simple, single-file calculator application built using Java Swing. It supports basic arithmetic operations.

Features
Addition (+)

Subtraction (-)

Multiplication (*)

Division (/)

Clear (C) button to reset the calculator.

Requirements
To compile and run this project, you only need one thing:

Java Development Kit (JDK) (Version 8 or newer).

How to Run
There are two common ways to run this project: using a terminal (command line) or using an IDE (like VS Code or IntelliJ).

1. Using the Terminal (Command Line)
This is the most straightforward way to run a single Java file.

Save the File Save the code into a file named SimpleCalculator.java.

Open Your Terminal Navigate to the directory where you saved the file.

Bash

cd /path/to/your/project
Compile the Code Run the Java compiler (javac). This will create a SimpleCalculator.class file.

Bash

javac SimpleCalculator.java
Run the Program Run the compiled Java code (java).

Bash

java SimpleCalculator
The calculator window should now appear on your screen.

2. Using an IDE (e.g., VS Code, IntelliJ, Eclipse)
Open the Project Open the folder containing your SimpleCalculator.java file in your IDE.

Find the Main Method Your IDE will automatically detect the public static void main(String[] args) method.

Run You can typically run the file by:

Clicking the small "Run" (play) button next to the main method or the class definition.

Right-clicking inside the file and selecting "Run 'SimpleCalculator.java'".

The IDE will handle the compilation and execution for you, and the calculator window will appear.
